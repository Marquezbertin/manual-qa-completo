# PT/EN Glossary

| PT | EN | Definition |
|----|----|------------|
| Caso de teste | Test case | Set of steps and expected result |
| Plano de teste | Test plan | Scope and approach document |
| Estratégia | Strategy | Generic testing approach |
| Bug / Defeito | Bug / Defect | Behavior diverging from expected |
| Regressão | Regression | Test to ensure changes didn't break existing |
| Smoke test | Smoke test | Minimal sanity validation |
| Pirâmide de teste | Test pyramid | Test distribution by level |
| Page Object | Page Object | UI automation pattern |
| Cobertura | Coverage | % of code/requirements exercised |
| Severidade | Severity | Defect impact on business |
| Prioridade | Priority | Fix urgency |
| Charters | Charters | Exploratory session mission |
| SLA | SLA | Service level agreement (e.g., time) |
| Vazamento de memória | Memory leak | Unreleased memory (endurance) |
| Quality Gate | Quality gate | Criterion that blocks pipeline |
| Shift-left | Shift-left | Test early in cycle |
| Rastreabilidade | Traceability | Link requirement↔test↔result |
