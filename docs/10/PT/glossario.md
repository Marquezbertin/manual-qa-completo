# Glossário PT/EN

| PT | EN | Definição |
|----|----|-----------|
| Caso de teste | Test case | Conjunto de passos e resultado esperado |
| Plano de teste | Test plan | Documento de escopo e abordagem |
| Estratégia | Strategy | Abordagem genérica de teste |
| Bug / Defeito | Bug / Defect | Comportamento divergente do esperado |
| Regressão | Regression | Teste para garantir que mudanças não quebraram o existente |
| Smoke test | Smoke test | Validação mínima de sanidade |
| Pirâmide de teste | Test pyramid | Distribuição de testes por nível |
| Page Object | Page Object | Padrão de automação de UI |
| Cobertura | Coverage | % de código/requisitos exercitados |
| Severidade | Severity | Impacto do defeito no negócio |
| Prioridade | Priority | Urgência de correção |
| Charters | Charters | Missão de sessão exploratória |
| SLA | SLA | Acordo de nível de serviço (ex: tempo) |
| Vazamento de memória | Memory leak | Memória não liberada (endurance) |
| Quality Gate | Quality gate | Critério que bloqueia pipeline |
| Shift-left | Shift-left | Testar cedo no ciclo |
| Rastreabilidade | Traceability | Vínculo requisito↔teste↔resultado |
