# Módulo 10 — Templates

> Copie e adapte conforme seu projeto. Campos entre `[...]` devem ser preenchidos.

## Test Plan Template

```
1. INTRODUÇÃO
   Objetivo: [validar release X]
   Escopo: [módulos A, B, C]
   Público: [stakeholders]

2. ITENS DE TESTE
   - [feature 1], [feature 2]

3. FORA DE ESCOPO
   - [feature legada não coberta]

4. ABORDAGEM
   Níveis: [unit, API, UI]
   Tipos: [regressão, smoke, exploratório]

5. AMBIENTE E DADOS
   Ambiente: [staging v2.3]
   Dados: [Faker pt_BR, anonimizados]

6. CRONOGRAMA E RESPONSÁVEIS
   Início: [data] | Fim: [data]
   QA Lead: [nome] | Testers: [lista]

7. RISCOS E MITIGAÇÕES
   Risco: [ambiente instável] → Mitigação: [reserva]

8. CRITÉRIOS DE ENTRADA/SAÍDA
   Entrada: [build ok, env pronto]
   Saída: [≥95% pass, 0 crítico aberto, cov ≥80%]

9. APROVAÇÕES
   Product: [ ]  Tech Lead: [ ]  QA: [ ]
```
